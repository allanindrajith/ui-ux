## Shared Architecture Standards

### Desktop Websites — 8-Block Conversion Architecture (Page 1 of Each Figma File)
1. **01 Hero** — Target buyer, 1-line outcome, 1-line how, primary CTA, and real product UI visual.
2. **02 Proof Bar** — Static row of 6 monochrome customer/partner logos (no carousel).
3. **03 Product Tour** — 3-step interactive product walkthrough with real UI mockups (1 sentence per step).
4. **04 How It Works** — Day 1 to first result in 3 clear steps.
5. **05 Case Studies** — 2 customer outcome cards (before/problem, headline metric, full story modal/link).
6. **06 Objections / FAQ** — 5 real buyer objections answered concisely in 2 lines each.
7. **07 Pricing** — 3 transparent tiers with the middle tier highlighted.
8. **08 Book a Demo** — 3-field form max, clickable calendar date/time picker, call agenda, and confirmation state.

### Mobile Apps — 8-Screen Flow Architecture (Page 2 of Each Figma File)
1. **01 Splash / Onboarding** — Brand intro, key features, and permissions CTA.
2. **02 Login / Sign-Up** — Email/password, social sign-in, and password recovery.
3. **03 Home / Feed** — Central dashboard hub with primary bottom navigation.
4. **04 Search / Explore** — Live query input, category filters, and browseable cards.
5. **05 Detail View** — Full single-item breakdown and primary action CTA.
6. **06 Action / Checkout / Form** — Multi-step booking, checkout, or logging workflow.
7. **07 Profile / Settings** — Account details, preferences, saved items, and toggles.
8. **08 Empty / Error / Confirmation States** — Dedicated guidance for zero-data, failure, and success states.
